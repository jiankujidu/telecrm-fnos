# 电销CRM —— 飞牛OS（fnOS）应用 安装说明

> **本版已改用飞牛官方 `fnpack 1.2.3` 打包**（手写包结构会被应用中心拒绝，提示「不符合系统要求」）。
> 包结构、manifest 字段、校验和全部由官方工具生成，符合 fnOS 应用中心规范。

- 应用名：电销CRM（telecrm）　版本：**1.2.1**
- 镜像：`jiankujidu/telecrm:1.2.1`（后端接口 + 管理后台，单镜像；ARM 机型自动用 `1.2.1-arm64`）
- 端口：**18080**　账号：`13800000001` / `123456`

## v1.2.1 更新了什么

### 1. 客户置顶（电脑端 / 手机端通用，新增）

- 客户列表新增「**置顶 / 取消置顶**」，置顶客户永远排在列表最前（带「置顶」标签/角标）；
- 电脑后台「客户」页每行有置顶按钮；手机 App 客户页每行菜单有置顶项；后端统一接口 `POST /api/customer/{id}/pin`；
- 数据备份 / 导入导出自动包含置顶状态。

### 2. 云端自动外呼（重点功能，v1.2.0 已含）

**你要的效果**：电脑上点一下，手机自动按顺序一通一通拨；能指定「从哪个客户开始」、
「每通之间隔多少秒」，还能随时暂停 / 跳过 / 结束。

**怎么实现的（电脑当大脑，手机当执行器）**

```
电脑后台 ──建任务(起点客户/条数/间隔秒数)──▶ 服务器 dial_push_task
                                               │
手机 App ◀──每 2 秒问一次 /dial-push/next ─────┤  后端按序号 + 间隔秒数发号
    │                                           │  原子领取，多台手机不会重复拨
    ├─ 自动拨出（有权限直拨，无权限自动唤起拨号界面）
    └─ 挂断后点结果 → /report → 后端推进下一条（并同步写一条通话记录）
```

好处：顺序、间隔、暂停全由后端决定，手机每轮都来问，**电脑上一改，手机 ≤2 秒立刻生效**；
手机只做「拨号 + 报结果」，App 退后台或换手机都不会乱序。

**用法（3 步）**

1. 电脑端：管理后台 → **云端自动外呼** → 新建任务（选范围 / 起点客户 / 条数 / 间隔秒数）→ **创建并立即开始**
2. 手机端：App 首页点 **云端自动外呼**（绿色横幅），**保持页面在前台**，自动按顺序拨出
3. 每通挂断后点一下结果；不点则倒计时结束自动进下一条（默认「未接听」，右上角设置可改）

## v1.1.0 更新了什么

| 你的问题 | 原因 | 现在 |
|---|---|---|
| 画像表不能编辑、不能删 | 后端 `CustomerController` **只有列表/转让接口，根本没有增删改** | 新增 `customer_profile` 画像表 + 完整的**增/改/删/批量删**接口，后台与 App 都能编辑删除 |
| 连电话也不能打 | ①Dart 里 `NavigatorService.context` 是 `late` 变量**从未赋值**，点拨号就抛异常；②Manifest 声明了 `CALL_PHONE` 却**从没动态申请过权限** | 重写拨号服务：先申请权限，有权限直拨、**没权限自动降级唤起拨号界面**（保证点了一定有反应），失败有明确提示和「去授权」入口 |
| 只有导入没导出 | 后端缺导出接口 | 客户/话单导出 Excel（客户导出含 30 列画像字段） |
| APK 免登录 | 之前按你要求做的免登录 | **改回强制登录**：打开 App 必须先填服务器地址 + 账号密码，去掉「先离线看看」 |
| 怕数据丢失 | 没有全量备份 | 新增**数据备份与恢复**：一键导出全库 JSON（15 张表），换机器/重装后上传即恢复，支持覆盖/追加两种模式 |

## 一、选哪个包

| 你的飞牛机型 | 用哪个包 | md5 |
|---|---|---|
| x86 主机 / x86 NAS（绝大多数） | **电销CRM-飞牛OS-v1.1.0-x86.fpk** | `25a20bbb308c6fa8e4adb1352b6ee7c3` |
| ARM 机型（ARM 盒子、瑞芯微/晶晨开发板） | **电销CRM-飞牛OS-v1.1.0-arm.fpk** | `52678be65fab8d5d1396f82ec1ff0c2a` |
| 不确定机型 / 上面两个都提示不符 | **电销CRM-飞牛OS-v1.1.0-通用.fpk**（platform=all） | `c6b00b81e160daee4b19623afcba99f0` |

看机型：飞牛桌面 → 系统设置 → 关于/设备信息看处理器；或 SSH 执行 `uname -m`，
`x86_64` → x86 包，`aarch64` → arm 包。

## 二、安装（5 步）

1. **开启 Docker**：飞牛桌面 → Docker → 确认已开启。
2. **上传**：把选好的 `.fpk` 拷到飞牛。
3. **手动安装**：应用中心 → 右上角 **手动安装** → 选该 `.fpk`。
4. **确认**：按提示确认权限与端口（默认 18080）。
5. **等「运行中」**：首次拉镜像 + 初始化数据库，1–3 分钟。

## 三、使用

| 项目 | 说明 |
|---|---|
| 桌面入口 | 桌面出现「电销CRM」图标，点击直开后台 |
| 访问地址 | `http://飞牛IP:18080/` |
| 手机 App | 装好 APK 后，**登录页「服务器地址」填 `http://飞牛IP:18080/api`** → 点「测试连接」→ 绿字「连接成功」→ 再登录 |
| 数据 | 首次启动自动建表并灌入演示数据（60 客户 / 126 通话记录），无需导入 SQL |

> 手机和飞牛要**在同一个局域网**（同一 WiFi / 同一路由器）。手机用 4G 是连不上的。

## 四、客户画像怎么用

后台左侧菜单：

- **客户管理** → 每行有「详情 / 编辑 / 画像 / 转让 / 删除」，还能勾选后**批量删除**
- **客户画像** → 独立的画像表，一屏看全部客户的 意向等级 / 行业 / 职位 / 微信 / 预算 / 决策人 / 拨打次数 / 画像小结，可按**意向等级筛选**，可编辑、可删除、可导出
- **数据备份** → 一键备份 + 上传恢复

手机 App：

- 客户列表 → 每行右侧有**拨号按钮**（绿色电话图标）和 **⋮ 菜单**（详情 / 编辑画像 / 删除）
- 客户详情 → 顶部有 **「拨打电话」** 和 **「编辑画像」** 两个大按钮
- 画像字段：性别、年龄、生日、行业、职位、微信、邮箱、备用电话、省/市、意向等级 A-D、预算、是否决策人、来源渠道、感兴趣产品、客户痛点、在用竞品、下次跟进时间、画像标签、画像小结

> 第一次点「编辑画像」会自动生成一条空画像，直接填就行。

## 五、数据备份与恢复（重要）

后台 → **数据备份**：

1. **立即备份下载** → 得到一个 `telecrm-backup-日期.json`，含 15 张表全部数据（团队/用户/客户/画像/跟进/通话记录/任务/订单/套餐/激活码…）
2. 换机器或重装后，选择这个文件 → **预览文件内容**（先核对条数）→ **确认恢复**
   - **覆盖**：清空现有数据后写入，结果与备份完全一致
   - **追加**：只补进缺失记录，保留现有数据

建议：每周备份一次；批量导入、批量删除前先备份。

## 七、还是装不上？

1. **换「通用」包**（platform=all，跳过架构校验）——最常见的原因就是架构不匹配。
2. **确认 fnOS 已更新到较新版本**：设置 → 系统更新。
3. **确认允许手动安装**：应用中心 → 设置。
4. **看日志**：SSH 进飞牛，`tail -f /var/log/trim_app_center/*`。

## 八、方案B：不用 .fpk，直接 Compose 部署（一定可用）

飞牛桌面 → Docker → **Compose** → 新增项目，名称 `telecrm`，粘贴 `compose/docker-compose.yml` 内容 → 确定。
访问同样是 `http://飞牛IP:18080/`。这条路与 .fpk 用完全相同的镜像和数据结构，绕过应用中心的全部校验。
