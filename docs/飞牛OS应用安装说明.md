# 电销CRM —— 飞牛OS（fnOS）应用 安装说明

> **本版已改用飞牛官方 `fnpack 1.2.3` 打包**（之前手写包结构会被应用中心拒绝，提示「不符合系统要求」）。
> 包结构、manifest 字段、校验和全部由官方工具生成，符合 fnOS 应用中心规范。

- 应用名：电销CRM（telecrm）　版本：**1.0.1**
- 镜像：`jiankujidu/telecrm:1.0.1`（后端接口 + 管理后台，单镜像；ARM 机型自动用 `1.0.1-arm64`）
- 端口：**18080**　账号：`13800000001` / `123456`

### v1.0.1 修了什么

| 问题 | 原因 | 处理 |
|---|---|---|
| 手机 App 数据读不出来 | 内置默认地址写死 `http://10.0.2.2:8080/api`——那是**安卓模拟器专用**地址，真机永远连不上，端口也不是 18080 | 默认改成局域网地址；登录页**新增服务器地址输入框** |
| 登录页没有填 IP 的地方 | 原本只能免登录进，无法指定服务器 | 登录页第一项就是「服务器地址」，带 **测试连接** 按钮，填错当场红字提示 |
| 静默离线不知道 | 连不上时直接进游客模式，用户以为是「数据没了」 | 首页顶部加橙色横幅「未连接服务器，当前为离线体验」+「去设置」 |
| 只有导入没有导出 | 后端缺导出接口 | 新增 `/api/export/customers`、`/api/export/call-records`，客户页、通话记录页各加「导出 Excel」按钮 |

## 一、选哪个包

| 你的飞牛机型 | 用哪个包 | md5 |
|---|---|---|
| x86 主机 / x86 NAS（绝大多数） | **电销CRM-飞牛OS-v1.0.1-x86.fpk** | `9f28e83b48bc3e621114e853aae69ebf` |
| ARM 机型（ARM 盒子、瑞芯微/晶晨开发板） | **电销CRM-飞牛OS-v1.0.1-arm.fpk** | `b06aad80f2b240c290190896ff28b288` |
| 不确定机型 / 上面两个都提示不符 | **电销CRM-飞牛OS-v1.0.1-通用.fpk**（platform=all） | `3657a50f5d546b77efe029dbfafb5d66` |

看机型：飞牛桌面 → 系统设置 → 关于/设备信息看处理器；或 SSH 执行 `uname -m`，
`x86_64` → x86 包，`aarch64` → arm 包。

## 二、安装（5 步）

1. **开启 Docker**：飞牛桌面 → Docker → 确认已开启。
2. **上传**：把选好的 `.fpk` 拷到飞牛。
3. **手动安装**：应用中心 → 右上角 **手动安装** → 选该 `.fpk`。
4. **确认**：按提示确认权限与端口（默认 18080）。
5. **等「运行中」**：首次拉镜像 + 初始化数据库，1–3 分钟。

## 三、使用

| 项目 | 说明 |
|---|---|
| 桌面入口 | 桌面出现「电销CRM」图标，点击直开后台 |
| 访问地址 | `http://飞牛IP:18080/` |
| 手机 App | 装好 APK 后，**登录页「服务器地址」填 `http://飞牛IP:18080/api`** → 点「测试连接」→ 绿字「连接成功」→ 再登录 |
| 数据 | 首次启动自动建表并灌入演示数据（60 客户 / 126 通话记录），无需导入 SQL |

> 手机和飞牛要**在同一个局域网**（同一 WiFi / 同一路由器）。手机用 4G 是连不上的。

## 四、数据目录

```
<应用数据目录>/mysql    ← 数据库
<应用数据目录>/uploads  ← 通话录音、导入的 Excel
```
卸载时勾选「保留数据」，重装后数据仍在。

## 五、还是装不上？

按这个顺序排查：

1. **换「通用」包**（platform=all，跳过架构校验）——最常见的原因就是架构不匹配。
2. **确认 fnOS 已更新到较新版本**：设置 → 系统更新。
3. **确认允许手动安装**：应用中心 → 设置。
4. **看日志**：SSH 进飞牛，`tail -f /var/log/trim_app_center/*` 能看到具体拒绝原因。

## 六、方案B：不用 .fpk，直接 Compose 部署（一定可用）

飞牛桌面 → Docker → **Compose** → 新增项目，名称 `telecrm`，粘贴
`docker-deploy/docker-compose.yml` 内容 → 确定。访问同样是 `http://飞牛IP:18080/`。
这条路与 .fpk 用完全相同的镜像和数据结构，绕过应用中心的全部校验。

## 八、导入 / 导出 Excel

- **导入**：客户页 → 导入（支持 xlsx/xls/csv），首行须为表头：姓名、手机号、公司、地址、来源、备注。
- **导出**：客户页 / 通话记录页 → **导出 Excel**，按当前筛选条件（全部/我的/下属、关键词、通话结果）导出，单次上限 2 万行，中文表头、中文状态。
